# 学生事务政策智能咨询与办事指引助手

> 赛题方向：AI+管理 ｜ 交付物：智能体（原型）+ Agent Skill
> 面向学生在综合测评、奖学金申请、评奖评优、竞赛认定、培养方案、学籍管理等事务办理中的"查政策难、问事烦、易出错"问题，提供基于政策知识库的智能咨询与办事指引。

## 项目结构

```
student-affairs-policy-assistant/
├── SKILL.md                    # Agent Skill 主文件（交付物）
├── README.md                   # 本说明文件
├── knowledge_base/             # 政策知识库（当前为示例数据，共 5 份）
│   ├── 奖学金评定管理办法.md
│   ├── 综合测评实施细则.md
│   ├── 学科竞赛认定办法.md
│   ├── 评奖评优管理办法.md
│   └── 学籍管理与培养方案指南.md
└── scripts/
    └── policy_agent.py         # 检索问答原型（纯 Python 标准库，零依赖）
```

## 技术路线

1. **知识库**：政策文件结构化为 Markdown（元数据 + 申请条件/办理流程/材料清单/注意事项/政策来源 五大章节），新增文件即插即用；
2. **意图识别**：关键词规则匹配事项类别（奖学金/综合测评/竞赛认定/评奖评优/学籍管理），优先在对应政策内检索；
3. **检索**：字符 bigram + 英文词 TF-IDF 余弦相似度，免分词、零依赖，适合中文短文本检索；
4. **回答组装**：命中政策按"政策解释 → 流程 → 材料 → 注意事项 → 来源"结构化输出，并抽取用户画像（年级、专业）做个性化提示；
5. **兜底与安全**：未命中时引导线下咨询；统一免责提示"以官方最新通知为准"。

## 快速开始

```bash
# 单次提问
python scripts/policy_agent.py --q "我是大二学生，想申请国家奖学金需要什么条件和材料？"

# 交互式问答
python scripts/policy_agent.py
```

运行环境：Python 3.8+，无第三方依赖。

## 示例效果

提问：`我大二转专业需要什么流程，学分怎么认定？`
→ 自动定位《学籍管理与培养方案指南》，输出转专业受理时间、考核流程、学分认定规则、申请材料及注意事项。

提问：`数学建模省一等奖综合测评分能加多少？`
→ 自动定位《学科竞赛认定办法》与《综合测评实施细则》，输出省级一等奖加分标准（8 分）与认定时限（赛后 30 日内申报、学期末集中认定）。

## 投入使用

1. 将 `knowledge_base/` 中的示例文件替换为学校/学院真实公开政策文件（保持相同结构）；
2. 可选：接入 LLM 将检索结果改写为更自然的对话回复（当前原型为纯检索式，可解释性强、零幻觉）；
3. 可选：将本技能安装至 WorkBuddy（复制到 `~/.workbuddy/skills/`），由智能体自动调用。
